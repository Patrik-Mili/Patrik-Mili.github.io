Splunk Home SIEM Lab

Installed Splunk Enterprise 10.6 on a Windows laptop and ingested Windows Security, System and Application event logs. Built custom dashboards, including a failed-logins panel (Event ID 4625), then simulated brute-force attempts against a test account to test sign-in throttling and the account lockout policy.

Key finding: the failed-login panel was also counting Application-log events that share ID 4625. Event IDs aren't unique across logs. Fixed by filtering to the Windows Security log only.

Vulnerability management

Nessus Vulnerability Remediation

Scanned my own machine with Tenable Nessus Essentials. Six of the seven Medium findings came from three default Splunk TLS certificate issues across active management ports. Built a private certificate authority with OpenSSL, issued CA-signed certificates and replaced Splunk's default TLS certificates.

Result: rescanned and confirmed Medium findings dropped from 7 to 1.
